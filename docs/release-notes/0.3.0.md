## What 0.3 ships

Automatic Hangul/English mode switching (`docs/SPEC-MODES.md` R1–R15,
E1–E8; lane assignment `docs/MILESTONES.md` §0.3, tracker issue #183).
The engine judges once at the composition boundary (R4) and each frontend
performs the switch; OFF restores the previous behaviour byte-for-byte
(R14/R15).

Per-phase issues #159–#181 are CLOSED; only #182 (this release close-out)
and #183 (tracker) remain OPEN on the 0.3 milestone. Measured branch
diff from `0.2.0`: `git diff --stat 0.2.0..HEAD -- libhunmin/src
frontends` — 78 files, +8000/−1098, including `libhunmin/src/wordset.c`
(+335) and `libhunmin/src/buffered_preedit.c` (judgement call site).

### The key (R13/E5, issue #159/#170)

Single press = manual Hangul/English switch; modifier + 한/영 = the
special-function namespace. Defaults shipped by the engine: voice =
`Alt + 한/영`, autoswitch = `Ctrl + 한/영`; the composition is selectable in
each config dialog. The on/off default is **OFF until release 0.3**
(B3, ruled 2026-10-11): the data ships separately and the feature enables
only where it is present.
Verified by: ctest `engine-buffered-preedit` (chord cases), per-frontend
surface-B lanes below.

### Surface B — one state, two surfaces (R13-정정)

The state is `hunmin_ic_set_option(ic, "autoswitch", 0|1)`; surface B
reads/shows it and names the engine's chord. It ships on all three
frontends (issues #176, #177, #175):
- fcitx5: config row reads the state and the engine-named key.
  Verified by: ctest `engine-d1-judgement` (tier D1).
- Android: IME settings screen (`SettingsActivity`, `method.xml`) +
  `AUTO_TOGGLE` dispatch writing the engine value (issue #174).
  Verified by: ctest `engine-android-e1` (`AutoSwitchTest`,
  `AutoSwitchGateTest`, `JudgementCorpusTest`).
- TSF: settings row advertises the switch only where the host honours it
  (issues #175, #215).
  Verified by: ctest tier F1 (`TsfJudgementTest.CorpusReplay`).

Cross-frontend parity (E7/R3, issue #180): the same corpus
(`tests/golden/judgement-r8.jsonl`) replayed on all three — fcitx5
skips `mode: latin` (host-owned), Android/TSF replay every case,
TSF asserting cumulative text for its per-syllable delivery.
Verified by: `engine-d1-judgement`, `JudgementCorpusTest`,
`TsfJudgementTest.CorpusReplay`.

### Persisted state (issue #203)

The autoswitch state persists across layer rebuilds (no frontend-stored
per-engine copy). Verified by: the persisted-state cases in
`engine-buffered-preedit` / `engine-wordset`.
